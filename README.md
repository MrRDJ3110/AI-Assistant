# Personal AI Assistant (Web Version)

A voice and text assistant that runs in your browser. It is the web version of my Python desktop project (Tkinter GUI + speech recognition), rewritten in JavaScript so anyone can use it from a link.

**Live demo:** https://YOUR-USERNAME.github.io/REPO-NAME/

## What it can do

- Tell the time and date
- Open Google, YouTube, Instagram and WhatsApp
- Search the web: `search for python tutorials`
- Answer questions from Wikipedia: `who is Albert Einstein`, `what is python`
- Tell jokes
- Save notes in your browser: `note: buy milk` (type `show notes` to read them)
- Repeat text: `say hello world`
- Voice input with the Mic button, and spoken replies

## Run it locally

Download `index.html` and open it in Chrome or Edge. No installation needed.

## Built with

HTML, CSS and JavaScript only. Voice uses the browser's Web Speech API, and answers come from the Wikipedia API.

## Notes

- Voice input works best in Chrome or Edge.
- A website cannot open apps installed on your PC, so that feature is only in the desktop (Python) version.
